# advisory-strategy — Estratégia Executiva de Transformação Digital

## O que faz
Traduz arquitetura de software/IA em valor de negócio: Time-to-Market e ROI, planejamento de adoção de IA em ondas, métricas DORA (Lead Time, frequência de deploy, taxa de falha de mudança) e conexão de melhorias de engenharia com metas estratégicas. Saída pronta para C-level.

## Quando usar
Quando a questão precisa ser respondida em linguagem de executivo ou com roadmap de adoção.

## Como se encaixa na banca
Fluxo: master (triagem) → platform | qa | security | strategy (consolidado pelo master). É a banca consultiva genérica — para o contexto HDI específico, use os correspondentes '-senior' (devex-platform-senior, devsecops-governance-senior, digital-transformation-exec).

## Como invocar
```bash
# Claude: copie advisory-strategy.md para ~/.claude/agents/ e invoque pelo nome
# Codex:  copie advisory-strategy.toml para ~/.codex/agents/
```
