# advisory-platform — DevEx e Platform Engineering

## O que faz
Redução de atrito do desenvolvedor: Internal Developer Portal (IDP/Backstage), ferramental assistido por IA (CLIs, extensões de IDE), templates de scaffolding para qualquer stack, catálogos de Skills Hub corporativos, servidores MCP e métricas de DevEx (framework SPACE, taxa de aceite de código IA, tempo de onboarding, velocidade de PR).

## Quando usar
Discussões sobre plataforma interna de dev, produtividade de time ou ferramentas de IDE.

## Como se encaixa na banca
Fluxo: master (triagem) → platform | qa | security | strategy (consolidado pelo master). É a banca consultiva genérica — para o contexto HDI específico, use os correspondentes '-senior' (devex-platform-senior, devsecops-governance-senior, digital-transformation-exec).
