# advisory-security — DevSecOps e Governança de IA

## O que faz
Segurança de aplicação e pipeline: SAST/DAST/SCA e varredura de segredos em CI/CD, proteção de dados (LGPD/GDPR) no software, isolamento de tenant em IA, governança de IA e alinhamento regulatório (ISO 27001, NIST, SOC 2).

## Quando usar
Pipeline de segurança, proteção de dados em código ou política de governança de IA.

## Como se encaixa na banca
Fluxo: master (triagem) → platform | qa | security | strategy (consolidado pelo master). É a banca consultiva genérica — para o contexto HDI específico, use os correspondentes '-senior' (devex-platform-senior, devsecops-governance-senior, digital-transformation-exec).
