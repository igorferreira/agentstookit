# devsquad-strategy — Estrategista da DevSquad

## O que faz
Define a abordagem e a priorização técnica da demanda antes da execução: riscos, dependências e ordem de ataque. Atua na frente da squad, junto ao devsquad-lead.

## Como se encaixa na squad
Fluxo padrão: po → architect → backend/frontend → qa → reviewer → devsecops. Respondem ao devsquad-lead.

```bash
# Claude: copie devsquad-strategy.md para ~/.claude/agents/
# Codex:  copie devsquad-strategy.toml para ~/.codex/agents/
```
