# advisory-qa — QA e Engenharia de Testes

## O que faz
Estratégia de testes e desenho da pirâmide, automação (unit/integração/E2E com Selenium, Playwright, Cypress, RestAssured, Postman), quality gates em CI, testes exploratórios e de regressão, performance e carga (k6, JMeter, Gatling), gestão de dados de teste, triagem de testes flaky e métricas de qualidade (defect escape rate, cobertura, MTTD).

## Quando usar
Estratégia de testes, automação, processo de QA ou testes instáveis.

## Como se encaixa na banca
Fluxo: master (triagem) → platform | qa | security | strategy (consolidado pelo master). É a banca consultiva genérica — para o contexto HDI específico, use os correspondentes '-senior' (devex-platform-senior, devsecops-governance-senior, digital-transformation-exec).

# Codex:  copie advisory-qa.toml para ~/.codex/agents/
