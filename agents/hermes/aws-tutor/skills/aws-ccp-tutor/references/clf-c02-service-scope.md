# CLF-C02 — Serviços em escopo e fora de escopo

Fonte: AWS exam guide oficial (In-Scope AWS Services / Out-of-Scope AWS Services). Ambas as listas são **não-exaustivas e sujeitas a mudança** pela AWS — trate como referência forte, não como lista fechada e definitiva.

Regra de uso: em aulas e simulados, priorize sempre os serviços da lista "em escopo". Serviços "fora de escopo" não devem virar pergunta de simulado nem ser ensinados como matéria cobrada — só mencione se Igor perguntar diretamente por curiosidade.
