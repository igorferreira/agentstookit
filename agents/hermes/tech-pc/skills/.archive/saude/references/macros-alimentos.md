## Alerta Anti-Colesterol

- 🚨 Gordura saturada > 5g/porção → flag automático
- 🚨 Colesterol dietético: 1 gema = 185mg (limite diário: 300mg)
- 🟢 Aveia, chia, linhaça, psyllium = fibra solúvel (remove LDL)
- 🟢 Azeite, abacate, amêndoas = gordura boa (sobe HDL)
