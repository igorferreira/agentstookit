# Plano Anticolesterol — Referência Rápida

Base para dietas de redução de LDL e elevação de HDL. Contexto Igor: LDL 187, HDL 31, Colesterol Total 233 (exames 05/08/2026).

## Metas Diárias

| | Alvo |
|---|---|
| Calorias | 1.200–1.400 (cutting) |
| Proteína | 100–120g |
| Gordura total | Máx 40g |
| **Gordura saturada** | **Máx 12g** ⚠️ |
| Fibra | Mín 25g |
| Colesterol dietético | Máx 300mg |

## Regras Diárias (não negociáveis)

1. **Aveia 40g todo dia** — fibra solúvel remove LDL
2. **Azeite 15ml todo dia** — gordura monoinsaturada sobe HDL
3. **Linhaça/chia 1 colher** — ômega-3 + fibra
4. **2 porções de legumes/verduras** — fibras + antioxidantes

## Alimentos PROIBIDOS (ou reduzir ao mínimo)

| Alimento | Motivo |
|---|---|
| Cream cheese / requeijão | Gordura saturada concentrada |
| Manteiga | Gordura saturada pura |
| Carnes gordas (picanha, costela) | Gordura saturada + colesterol |
| Frituras | Gordura trans + inflamação |
| Embutidos (bacon, salsicha, salame) | Gordura saturada + sódio |
| Leite integral / creme de leite | Gordura saturada |

## Trocas Inteligentes

| Substituir | Por |
|---|---|
| Manteiga | Azeite de oliva |
| Cream cheese | Queijo minas frescal ou cottage |
| 3 ovos inteiros | 1 gema + claras (reduz 370mg de colesterol) |
| Carne vermelha gorda | Patinho moído ou frango |
| Arroz sozinho | Arroz + feijão/lentilha (fibra) |

## Efeito da TRT

Testosterona suprafisiológica (>1000 ng/dL) deprime o HDL. Dieta ajuda mas o ajuste mais impactante é **reduzir a dose da TRT**. Levar pra médica.

## Monitoramento

- Perfil lipídico em 3 meses
- Meta: LDL < 130 em 3 meses, < 100 em 6 meses
- HDL > 40 (difícil com TRT alta, mas mirar)
