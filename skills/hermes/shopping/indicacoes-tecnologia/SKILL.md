# Indicações de tecnologia para amigos

## Fluxo
1. Usuário cola o pedido do amigo no chat. Identificar: item, uso principal, orçamento (se não tiver, perguntar UMA vez e seguir com estimativas em camadas).
2. Pesquisar preços reais do dia (web_search + páginas; sites BR com proteção — Mercado Livre, Shopee, Amazon, KaBuM — navegar com browser como usuário real, ver skill browser-use).
3. Montar resposta em 3 camadas: BÁSICO / RECOMENDADO / TOP, com preço atual e 1 linha do porquê de cada. Se o amigo tiver perfil claro (ex.: só WhatsApp e YouTube), dizer que o básico já resolve.
4. Registrar em ~/MEGA/Documentos/indicacoes_tecnologia/ (arquivo 2026-MM-DD_PEDIDO-<slug>-<quem>.md) e atualizar a tabela do INDEX.md.

## Formato da entrega
- Resposta para o amigo SEMPRE dentro de um bloco de código (botão copiar, Usuário manda por WhatsApp).
- Tom informal e leve, sem jargão técnico desnecessário, português do Brasil.
- Nunca recomendar por marca/lealdade — por preço-atual × necessidade.
- Usar como apoio os agentes especialistas: Duda (celular-doc) para smartphones, tech-pc para PC/notebook/hardware.

## Registro
canônico: ~/MEGA/Documentos/indicacoes_tecnologia/INDEX.md (append-only, um arquivo por pedido).
